# מוצא מסלולי טיולים בישראל

אתר שבו מקלידים שם של מקום בישראל ומקבלים המלצות למסלולי טיול בסביבה, עם תחזית מזג אוויר וקישורים לתיאור כל מסלול.

**האתר החי:** https://guy4study.github.io/israel-hikes/

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף ו**מספר הגרסה** |
| `style.css` | העיצוב |
| `app.js` | החיפוש, הסינון, מזג האוויר והקישורים |
| `trails.js` | רשימת המסלולים ורשימת המקומות |
| `CHANGELOG.md` | מה השתנה בכל גרסה |

## איך מוציאים גרסה חדשה

1. מבצעים את השינוי בקוד.
2. ב-`index.html` מעלים את מספר הגרסה בכל המקומות: בשורה `גרסה X.Y.Z` בתחתית הדף ובכל `?v=X.Y.Z`.
3. מוסיפים רשומה חדשה בראש `CHANGELOG.md`.
4. שומרים ומעלים:
   ```
   git add -A
   git commit -m "Release X.Y.Z"
   git tag -a vX.Y.Z -m "גרסה X.Y.Z"
   git push
   git push origin vX.Y.Z
   ```
5. אחרי 1–2 דקות האתר החי מתעדכן. בתחתית הדף תופיע הגרסה החדשה.

## חזרה לגרסה קודמת (אם משהו נשבר)

לא מוחקים היסטוריה. מחזירים את הקבצים מהגרסה הטובה ומוציאים אותם כגרסה חדשה:

```
git checkout v1.0.0 -- index.html style.css app.js trails.js
```

אחר כך מעדכנים את מספר הגרסה ב-`index.html` למספר חדש (למשל 1.1.1), כותבים ב-`CHANGELOG.md` "חזרה לתוכן של 1.0.0", ומבצעים את שלב 4 שלמעלה.

כל הגרסאות שפורסמו מופיעות בדף התגיות של המאגר: https://github.com/guy4study/israel-hikes/tags
